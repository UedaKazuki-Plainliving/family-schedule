# シナリオテスト仕様書（ユーザーシナリオ）

- バージョン：v0.1
- 目的：ペルソナのユーザーストーリーが通して成立することを確認する
- 実装：Playwright for Java (Browser)

各シナリオは1つのブラウザセッションで一連の操作を行い、最終結果を検証する。

---

## TC-SC-01 お母さんの朝（最重要ユーザーの主利用シナリオ）

**ペルソナ**：お母さん（48, 医師、閲覧中心）

| Step | 操作 | 期待結果 |
|------|------|---------|
| 1 | アプリを開く（LocalStorage 空） | 利用者選択画面が表示される |
| 2 | "お母さん" をタップ | スケジュール画面へ遷移 / LocalStorage に "お母さん" が保存 |
| 3 | 画面を確認 | 今日と明日、家族5人分の予定が表示される |
| 4 | ブラウザを閉じて再度開く | 利用者選択画面をスキップし、直接スケジュール画面が開く（FR-20） |
| 5 | "+追加" → 誰が=いちろう（1タップ切替）→ 内容="学童お迎え" → 保存 | 3ステップ以内で登録完了（FR-21）、トースト |

**受け入れ基準**：すべて成功し、FR-20, FR-21, FR-22 を実証する。
