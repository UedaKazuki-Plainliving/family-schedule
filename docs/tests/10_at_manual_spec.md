## 1. 受け入れテスト方針

### 1-1. このテストの目的

このテストは、**家族のみんなが実際に使ってみて「使えるか・使いやすいか」を確かめる**ためのものです。

難しいプログラムの話ではなく、「ちゃんと動くか」「わかりやすいか」「困らないか」を家族の目線でチェックします。

### 1-2. テストに参加する人

| 役割 | 誰が担当するか |
|------|--------------|
| テスト実施者 | 実際の家族メンバー（お父さん・お母さん・長女・次女） |
| テスト観察者 | 開発担当者（操作は口出ししない。メモだけとる） |
| テスト記録係 | 開発担当者または保護者 |

### 1-3. 合格の基準

以下をすべて満たすと「合格」とします。

- **必須（H）のシナリオ**をすべてクリアできること
- 各シナリオで「使いやすさ評価」が **3点以上**（5段階中）であること
- **操作に詰まって止まってしまうことがないこと**（1分以上ひとりで悩んでしまう場面がないこと）
- 「不正なメンバーです」などの**意味のわからないエラーが出ないこと**（AT-GR-02 は除く。バグとして記録する）

### 1-4. 実施環境

| 項目 | 内容 |
|------|------|
| 端末 | 実機スマートフォン（iOS または Android） |
| ブラウザ | Safari（iPhone）または Chrome（Android） |
| ネット接続 | 自宅の Wi-Fi に接続した状態 |
| アプリのインストール | 不要。ブラウザでURLを開くだけ |
| テスト前の準備 | テスト用データ（サンプルの予定）を入れておく |

### 1-5. テストの進め方

1. テスト担当者が端末とURLを用意します
2. 家族メンバーにシナリオを渡し、自分で読んで操作してもらいます
3. 観察者は口出しせず、どこで迷ったかをメモします
4. テスト後に「使いやすさチェック」と「評価コメント」を記入します

## 2. ペルソナ定義

### P-01 お父さん

| 項目 | 内容 |
|------|------|
| 特性 | スマホやパソコンに慣れている。操作はミスが少ない |
| 主な使い方 | 朝の予定確認、家族全体のスケジュール管理、メンバー追加 |
| 使うタイミング | 朝ごはんの前、週末 |
| 困りやすいこと | 細かい操作より「情報が見やすいか」を気にする |

### P-02 お母さん

| 項目 | 内容 |
|------|------|
| 特性 | 家族みんなの予定を管理している。急いでいるときに操作ミスをすることがある |
| 主な使い方 | 予定の登録・修正・削除。誤操作後の「元に戻す」をよく使う |
| 使うタイミング | 朝・昼・夕方と頻繁に使う |
| 困りやすいこと | 間違えて消してしまったとき。入力欄がどこにあるかわからないとき |

### P-03 長女（中学生）

| 項目 | 内容 |
|------|------|
| 特性 | スマホ操作が得意。すばやくタップする |
| 主な使い方 | 自分の予定を自分で登録・確認する |
| 使うタイミング | 学校から帰ってきたとき、夜 |
| 困りやすいこと | 他の家族の予定を誤って触ってしまうこと |

### P-04 次女（小学生）

| 項目 | 内容 |
|------|------|
| 特性 | スマホ操作に慣れていない。誤タップや長押しをしてしまうことがある |
| 主な使い方 | 自分の予定を見るだけ |
| 使うタイミング | 学校の前・後 |
| 困りやすいこと | 知らないうちに何かを消したり変えたりしてしまうこと |

| V-05 | 操作の制限 | ログインしていない人の予定は編集できないか（誤操作防止） | AT-P03-03 |
| V-06 | メンバー管理 | 新しいメンバーを追加・名前変更・削除できるか | AT-P01-03 |
| V-07 | 新メンバーへの予定登録（バグ確認） | 追加したばかりのメンバーに予定を登録しようとするとエラーが出るか | AT-GR-02 |

| V-09 | 来月以降の予定 | 来月の予定を見たり登録したりできるか | AT-GR-03 |
| V-10 | 長い文字の表示 | 長い予定内容が画面からはみ出さずに表示されるか | AT-GR-04 |
| V-11 | 誤操作への耐性 | 長押しや誤タップでおかしなことが起きないか | AT-P04-02 |
