## 各ペルソナのレビューコメント（MVP 受け入れレビュー）

### お父さん（51歳・SE）

- 「パッと開いてパッと確認」が実現できている。LocalStorage に記憶して2回目以降すぐ見られる（FR-20）のは助かる。
- API が REST で整理されていて運用的にも安心。
- **結論：受け入れ可**。将来的には BL-11（入力候補サジェスト）を入れたい。

### お母さん（48歳・医師、最重要ユーザー）

- 5人×2日のグリッドで家族全員の予定が一目。
- 「誰が」がボタン5つ並列で1タップ切替（FR-22）、登録が3ステップ以内（FR-21）で回る。
- 削除ダイアログに内容が出る（FR-17）、削除ボタンが色で区別（FR-19）、押し間違えを防げる。
- **結論：受け入れ可**。BL-16（削除 UNDO）は早めに欲しい。

### そよ（中3）

- スマホで片手操作できる。フリックで日付移動もできる。
- 絵文字含めた入力で100文字ぎりぎりも問題なく通る。
- **結論：受け入れ可**。BL-12（送り迎え要フラグ）は次回以降希望。

### ゆうり（小6・閲覧中心）

- 起動して画面を眺めるだけで家族の予定がわかる。
- 長押しで誤って編集画面に入らないのが安心（FR-23）。
- **結論：受け入れ可**。BL-18（閲覧専用モードで "+追加" を消したい）は将来。

### いちろう（小2・本人利用なし）

- 本人はアプリを使わないので、データとして登場することを親レビューで確認。
- 親が代理登録ができる（"誰が"ボタンで "いちろう" を1タップで切替）。
- **結論：受け入れ可**。BL-10（ふりがな）は将来本人利用時に対応。
