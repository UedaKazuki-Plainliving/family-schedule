## 確認観点

- 遷移先の URL / ルーティング（SPAなら画面ID）
- 画面の可視要素（モーダルが開いている／閉じている）
- LocalStorage の状態変化（T03〜T07 で currentUser が保存される）
- トーストの出現・消滅
- 連続遷移しても画面ID が崩れない（例：S-02 → S-03 → S-02 → S-04 → S-05 → S-02）
