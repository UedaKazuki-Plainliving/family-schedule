# ユーザーペルソナ - 家族スケジュール共有システム

- バージョン：v0.2（本人ヒアリングを反映した定義）
- 更新履歴：
  - v0.1：仮置き
  - v0.2：年齢・職業・利用スタンスを本人ヒアリングに基づき修正。ゆうり・いちろうは閲覧中心であることを明記。

本システムを使う家族5人のペルソナを定義する。
ペルソナは要件定義・設計・テストの各フェーズで「ユーザー視点のレビュアー」として参照される。

---

## ペルソナ1：お父さん（51歳・システムエンジニア）

- **役割**：会社員（SE）。仕事で日々忙しい。
- **ITスキル**：高。本人が技術者なので操作面でのハードルは低い。
- **利用シーン**：仕事の合間、通勤中、夜。
- **困りごと**：
  - 毎日の家族の予定をすぐ忘れる。
  - 忙しいので、アプリを開くたびに画面遷移が多いとストレス。
- **求めるもの**：
  - **パッと開いてパッと確認**できる。
  - 自分の予定入力は「出社／在宅」「飲み会／イベントの有無」などシンプルなもの中心。
- **入力例**：
  - 「在宅」「出社」
  - 「飲み会（夜遅い）」「会社のイベント」
- **主な利用パターン**：閲覧メイン＋自分の予定の短文入力。
- **使う頻度**：1日2〜3回。

## ペルソナ2：お母さん（48歳・医師）

- **役割**：医師。仕事で忙しい。**子どもの送り迎えを主に担当** → 家族全員の予定把握が最も必要。
- **ITスキル**：中〜低。**スマホ操作にはあまり詳しくない**。
- **利用シーン**：勤務の合間、帰宅後、朝の支度中（スマホ片手）。
- **困りごと**：
  - 子ども3人＋夫の予定を一番把握しておきたい立場なのに、情報が散らばっている。
  - 複雑なアプリは覚える余裕がない。
- **求めるもの**：
  - **誰が何日に何をするか**が一画面で見えること。
  - **操作は極力少ないステップ**で完結すること（ボタンが多いと混乱する）。
  - 家族全員の予定を「見る」ことに最適化されたUI。
- **主な利用パターン**：閲覧中心＋自分と子どもの予定入力。
- **使う頻度**：1日4〜5回。**一番のヘビーユーザー**。

## ペルソナ3：そよ（中学3年生・女の子）

- **役割**：受験生。塾・部活で忙しい。送り迎えはお母さん。
- **ITスキル**：高。スマホをよく使う世代。
- **利用シーン**：通学・休み時間・帰宅後、常にスマホ。
- **困りごと**：
  - 塾や部活の予定変更が頻繁。お母さんに口頭で伝えるのが面倒。
  - 送り迎えしてもらうには「いつ・どこへ」を早く共有したい。
- **求めるもの**：
  - スマホで**片手、数タップ**で予定を入れられる。
  - フリックで日付移動などスマホらしい操作感。
  - 時刻入力は不要（場所と用事だけ書ければ十分）。
- **主な利用パターン**：自分の予定の入力＋家族の予定の閲覧。
- **使う頻度**：1日2〜3回。

## ペルソナ4：ゆうり（小学6年生・女の子）

- **役割**：あまり外出しないタイプ。家で過ごすことが多い。
- **ITスキル**：中。家族のタブレットや親のスマホを触る程度。
- **利用シーン**：家のリビング、親のスマホを借りたとき。
- **困りごと**：
  - 自分の予定はほぼ固定（家にいる）ので、入力する必要がない。
  - ただし家族（特にお母さん）の予定は知りたい。
- **求めるもの**：
  - **閲覧専用で十分**。入力機能は（当面）自分では使わない。
  - 読みやすいこと。
- **主な利用パターン**：**閲覧のみ**。
- **使う頻度**：1日1回程度。

---

## ペルソナ5：いちろう（小学2年生・男の子）

- **役割**：低学年。まだスマホを自分で操作することが少ない。
- **ITスキル**：とても低い。**現時点では本人はアプリを使わない想定**。
- **利用シーン**：（直接の利用者としては想定外）
- **困りごと**（保護者代弁）：
  - 予定はお母さん／お父さんが把握・入力する。
  - 本人用の機能は当面不要。
- **求めるもの**（保護者代弁）：
  - 予定データとしては「いちろう」が存在し、親が代理で登録できればよい。
  - 将来、本人が使い始めたときに困らない程度のシンプルさ。
- **主な利用パターン**：**本人利用なし（将来：閲覧）**。親が代理で入力。
- **使う頻度**：本人0回。データとしてはほぼ毎日登場。

## ペルソナ横断の合意事項

| 項目 | 合意内容 |
|---|---|
| 入力する人 | 主にお父さん・お母さん・そよ（3名） |
| 閲覧のみの人 | ゆうり・いちろう（2名）※いちろうは現時点で本人利用なし |
| 表示単位 | 「今日」と「明日」の2日分のみ常時表示 |
| 日付の進め方 | フリック（横スワイプ）で前後の日に移動 |
| 入力項目 | 「誰が」「いつ（日付）」「何を（フリーテキスト）」の3つだけ |
| 時刻 | 入力不要 |
| 利用デバイス | スマホ優先（片手操作）、PCでも見られればよい |
| 認証 | 家族5人の中から「誰として使うか」を選ぶ簡易方式（最初は厳密な認証なし） |
| 最重要利用者 | **お母さん**（閲覧の頻度・重要度が最も高い）→ UIはお母さんに最適化 |
