## 検出された不具合・観察

- **OBS-1**：`<script>` などHTMLタグ文字列がそのままDBに保存される。現状フロントは `textContent` で出力するため発火しないが、防御層は1枚しかない（要 EX-003 で実機確認）。
- **OBS-2**：改行を含むテキストを保存できるが、画面上は改行が描画されず1行表示になる。入力と表示の不一致。
- **OBS-3**：ZWJ家族絵文字（👨‍👩‍👧‍👦）はユーザーには1絵文字に見えるが内部7コードポイント。100文字制限が「家族絵文字14個」で打ち切られる感覚になる。仕様としては正しいが、ヘルプテキストに補足が望ましい。
