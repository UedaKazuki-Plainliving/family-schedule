## S-02 スケジュール画面（メイン）

### 目的
今日と明日の予定を人ごとに表示する。フリックで前後日移動。

### レイアウト（スマホ縦）

```
┌───────────────────────────────────────┐
│ [👤 お父さん]  家族スケジュール  [今日に戻る] [⚙] │   ヘッダ（56px高）
├───────────────────────────────────────┤
│              2026-04-24              │
│        今日(金)      明日(土)          │   日付ラベル（列見出し）
├───────────┬───────────────────────────┤
│ お父さん   │ 在宅         │ 出社       │
├───────────┼─────────────┼───────────┤
│ お母さん   │ 病院(夜当直)  │ 予定なし    │
├───────────┼─────────────┼───────────┤
│ 長女      │ 部活         │ 塾         │
├───────────┼─────────────┼───────────┤
│ 次女    │ 予定なし     │ 予定なし    │
├───────────┼─────────────┼───────────┤
│ 長男  │ サッカー教室  │ 予定なし    │
├───────────┴─────────────┴───────────┤
│                                       │
│                           [ +追加 ]   │   FAB（右下、56×56px）
└───────────────────────────────────────┘
```

### 要素

| ID/セレクタ | 種別 | 動作 |
|---|---|---|
| `#btn-switch-user` | ボタン（ヘッダ左） | 「👤 {名前}」を表示。タップで LocalStorage をクリアし S-01 へ戻る |
| `#btn-today` | ボタン（ヘッダ右） | タップで表示日付を today/tomorrow に戻す |
| `#btn-member-settings` | ボタン（ヘッダ右端） | ⚙ アイコン。タップで S-06 を開く |
| `#date-today`, `#date-tomorrow` | ラベル | 表示中日付（フリックで変化） |
| `.schedule-cell[data-member-id][data-date]` | セル | 中の予定を縦に並べる。予定なしなら "予定なし" |
| `.schedule-item` | 予定アイテム | **タップ**でインライン編集モードに切り替わる（FR-23：長押しでは開かない） |
| `.schedule-item-text` | テキスト表示 | 通常時の予定内容テキスト（クリックでインライン編集へ） |
| `.schedule-item-delete` | ✕ボタン（右上） | タップで即削除 → UNDOトースト（FR-27） |
| `#btn-add` | ボタン（FAB） | タップで S-03 を開く |
| 画面全体 | スワイプ領域 | 左フリック → +1日、右フリック → -1日 |

### ビューポート（DS-1）

- スマホ縦画面（iPhone SE 相当：375×667px）で **ヘッダ + 日付見出し + 5行×2列のグリッドが初期ビューポート内にスクロールなしで収まる**こと。
- 各 `.schedule-cell` の最小高さ：`(667 - 56 - 40 - 56) ÷ 5 ≒ 103px` を目安（FAB領域除く）。
- セル内の予定が3件以上の場合はセル内で縦スクロール。

### 表示ロジック

- 起動時に `GET /api/schedules?from={viewDate}&to={viewDate+1}` を叩く
- 結果を「人ごと × 日付ごと」のマップに整形して描画
- フリックで `viewDate` を更新し、再取得

### バリデーション
なし（閲覧画面）。

## S-03 予定入力フォーム（モーダル）

### 目的
新規予定を登録する。

### レイアウト

```
┌───────────────────────────────┐
│  予定を追加                [×]│
├───────────────────────────────┤
│ 誰が？                         │
│ [お父さん][お母さん][長女][次女][長男] │   ← FR-22: メンバーを横並びボタン
│       ^^^^^ (選択中は色反転)   │
│                               │
│ いつ？                         │
│ [ 2026-04-24 ▾ ]               │
│                               │
│ 何を？ (100文字まで)           │
│ ┌───────────────────────────┐ │
│ │                           │ │
│ │                           │ │
│ └───────────────────────────┘ │
│ ⚠ エラー欄 (条件成立時のみ)     │
│                               │
│        [キャンセル] [ 保存 ]   │
└───────────────────────────────┘
```

### 要素

| ID | 種別 | 初期値 | 動作 |
|---|---|---|---|
| `#form-title` | ラベル | "予定を追加" | ― |
| `.who-btn[data-member-id]` | ボタン ×5 | 現在の利用者が選択状態 | タップで選択切替（FR-22, 1タップ）。**スマホ幅が狭い場合は折り返して2段表示可。いずれの配置でも1タップで切替可能であること（DS-2）** |
| `#date-input` | 日付入力 | 表示中の日付 | 変更可 |
| `#content-input` | textarea | 空 | 最大100文字 |
| `#error-msg` | エラー表示 | 非表示 | バリデーションNGで表示 |
| `#btn-save` | ボタン | ― | `POST /api/schedules` を叩く。成功時トーストを出してモーダルを閉じる。**リクエスト送信中は disabled にしラベルを "保存中..." に変更（DS-4）** |
| `#btn-cancel` | ボタン | ― | 何もせず閉じる |
| `#btn-close` (×) | ボタン | ― | キャンセルと同じ |

### バリデーション（FR-10, FR-18）

| 条件 | メッセージ |
|---|---|
| 内容が空文字 or 空白のみ | 「内容を入力してください」 |
| 内容が101文字以上 | 「内容は100文字以内で入力してください」 |
| 誰が未選択（通常起きない） | 「誰を選んでください」 |

保存成功時：トースト「保存しました」（FR-16）。

## S-04 インライン編集（スプレッドシート方式）

S-02 上で予定アイテムをタップすると、同じ位置のままテキストエリアに切り替わる（画面遷移なし）。

### 表示状態

```
┌─────────────────────────────────────────┐
│ ... (グリッド)                            │
│ 長女 │ ┌──────────────────────┐  │ ...  │
│      │ │ 部活（青枠・フォーカス）│  │      │
│      │ └──────────────────────┘  │      │
│ ...                                      │
└─────────────────────────────────────────┘
```

### 要素

| セレクタ | 種別 | 動作 |
|---|---|---|
| `.schedule-item-input` | textarea | 現在の内容が入力済み。Enter（単独）で保存、Escape でキャンセル |
| `.schedule-item-editing` | 状態クラス | 青枠 (`#2e6bb8`) + ドロップシャドウで編集中を視覚表示 |
| 入力欄外をクリック | blur イベント | Enter と同じく保存を試みる（内容が変わっていれば保存、未変更/空ならキャンセル） |

### バリデーション（FR-18, FR-26）

| 条件 | 動作 |
|---|---|
| 内容が空または未変更 | 保存せずキャンセル（元のテキストに戻る） |
| 101文字以上 | トースト「100文字以内で入力してください」、入力欄は残る |

保存成功時：`PUT /api/schedules/{id}`、トースト「更新しました」（FR-16）。

## S-06 メンバー管理モーダル

### 目的
家族メンバーの追加・名前変更・削除を行う（最大10名）。S-02 ヘッダの ⚙ ボタンから開く。

### レイアウト

```
┌───────────────────────────────┐
│  メンバー管理              [×]│
├───────────────────────────────┤
│ 最大10名まで登録できます       │
│                               │
│ お父さん       [名前変更] [削除] │
│ お母さん       [名前変更] [削除] │
│ 長女           [名前変更] [削除] │
│ 次女           [名前変更] [削除] │
│ 長男           [名前変更] [削除] │
│                               │
│ [ 名前を入力（20文字まで） ] [追加] │
│ ⚠ エラー欄 (条件成立時のみ)   │
└───────────────────────────────┘
```

### 要素

| ID/セレクタ | 種別 | 動作 |
|---|---|---|
| `#btn-member-modal-close` (×) | ボタン | モーダルを閉じ S-02 に戻る |
| `.member-manage-item` | 行 × N | メンバー名 + 操作ボタン |
| `.member-manage-name` | テキスト | メンバー名表示 |
| 名前変更ボタン | ボタン | クリックで行内に入力欄を展開。確定で `PUT /api/members/{id}` |
| 削除ボタン | ボタン | 確認ダイアログを経て `DELETE /api/members/{id}` |
| `#member-add-input` | テキスト入力 | 最大20文字 |
| `#btn-member-add` | ボタン | `POST /api/members` を呼び出し一覧を再描画 |
| `#member-modal-error` | エラー表示 | バリデーションNGで表示 |

### バリデーション

| 条件 | メッセージ |
|---|---|
| 名前が空 or 空白のみ | 「名前を入力してください」 |
| 名前が21文字以上 | 「名前は20文字以内で入力してください」 |
| 同名のメンバーが存在する | 「同じ名前のメンバーが既に存在します」 |
| 10名以上で追加しようとした | 「メンバーは最大10名までです」 |
| 削除対象に予定が紐づいている | 「このメンバーには予定が登録されています。先に予定を削除してください。」 |

## 入力誤操作防止（FR-23）

- 予定行（`.schedule-item`）への **長押し（>300ms）ではインライン編集モードにならない**。`contextmenu` イベントも無反応。
- ダブルタップ拡大を抑止するため `touch-action: manipulation`。
- フリック判定の閾値：**水平30px以上、垂直20px以下**。閾値未満はタップ扱い。
- `.schedule-item-delete`（✕ボタン）のタップは click のみ。ドラッグ・長押しは無効（フリックとの衝突防止）。
